# Passo a passo

## 1. Gere um README.md

Utilize o template `assets/readme-md.template.md` para criar um README.md básico para o projeto. Solicite ao usuário as informações que preencherão as seções que não sejam técnicas.

O README.md deve ficar na raiz do projeto.
